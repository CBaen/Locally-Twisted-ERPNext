# Customer Portal Icon Set

Premium Concierge icon set for the Locally Twisted customer account portal.

These icons translate the approved B concept into real implementation assets.
They are hand-authored SVG files, not extracted from Instagram or from a
third-party UI kit. Use them for the customer/client account portal only unless
the broader site explicitly adopts this direction.
