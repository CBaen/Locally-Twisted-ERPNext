Contestant 3 — The Coloring Page Frame. This mockup treats the design tool as a coloring page for grown-ups, not a configurator. The customer taps a shape, colors its regions, adds it to a composition, and the page builds into their event's color story. Every screen is a static HTML file — open by double-click, no server needed. Frappe-recreatable via www/design-studio.html + page-scoped CSS/JS in a custom Frappe app.

Research grounding: 6 areas researched, 19 cited sources. Key citations: Baymard Institute (swatch scroll pattern), Pigment app (Tap-to-Fill UX), Frappe portal pages docs (build feasibility confirmed).
