    Physics math (binding reference for Frappe build)

    // === Quad cluster radiates OUTWARD from center rope ===
// Tie point is ON the curve; balloon centers are offset by ~0.85 * radius
// This creates the dense interlocking tube, NOT a hollow flat ring

// === Arch curve (half-circle) ===
//   x(theta) = cos(theta) * (archWidth/2)
//   y(theta) = sin(theta) * archHeight
// Tangent angle at this point: angle - PI/2 (perpendicular to radial)

// === 45-degree spiral rotation per cluster ===
//   spiralAngle = PI / 4
//   clusterRotation = clusterIndex * spiralAngle
// Each balloon in the quad points in one of 4 directions (every PI/2)
// Plus the cluster's spiral rotation:
//   angleInCluster = balloonInCluster * (PI/2) + clusterRotation
// This is a PHYSICAL rotation - the balloon positions actually rotate.
// Spiral effect comes from THIS, not from color rotation.

// === Color logic depends on Style ===
// SWIRL (max 4 colors): each balloon in quad gets next color
//   colorIndex = balloonInCluster % colors.length
//   With the 45-degree physical rotation, this creates a barber-pole twist.
// LAYERED (max 8 colors): all balloons in cluster same color, 2 quads per band
//   bandIndex = floor(clusterIndex / 2)
//   colorIndex = bandIndex % colors.length
//   Pattern: AA-BB-CC-DD across the arch (no spiral within a band)

// === Real-world units (catalog-grounded) ===
// 11" balloon = 0.458 ft radius = 0.917 ft diameter
// 40 balloons / 5 feet of arch (industry standard)
// 8 balloons / foot = 2 quad clusters / foot

    Differences from the prior (incorrect) version

    The first iteration of this prototype used a 2D diamond cluster on a 2D arch curve - balloons appeared FLAT, like a hollow ring. That math was wrong. GL's actual implementation has balloons radiating outward from the rope in 3D, with a 45-degree physical rotation per cluster creating the dense nested look. The spiral effect is geometric (physical rotation), not color-coded.

    Visual tell: in GL's correct version, you see balloons distributed AROUND the rope (some pop forward via translateZ, some recede), giving a 3D tube appearance. In the wrong version, all balloons sat flat in the page plane.
