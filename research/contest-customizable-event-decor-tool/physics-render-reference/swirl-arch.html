    Physics math (binding reference for Frappe build)

    // === Arch curve (half-circle) ===
// Parametrize theta from pi -> 0 across cluster_count steps:
//   x(theta) = cx + rx * cos(theta)
//   y(theta) = cy - ry * sin(theta)         (SVG y-down; minus -> upward)
//
// Cluster orientation: rotation = pi/2 - theta
//   Rotates the cluster diamond so its "top" balloon points
//   toward the outward normal of the arch at every position.
//   Verified: theta=pi/2 -> rot=0   (no rotation at top of arch)
//             theta=0    -> rot=pi/2 (rotates 90 at right foot)

// === Cluster geometry (4 balloons, diamond pack) ===
// Balloon position offsets (default, untransformed):
//   pos 0 (top):    ( 0, -offset)
//   pos 1 (right):  ( offset, 0 )
//   pos 2 (bottom): ( 0,  offset)
//   pos 3 (left):   (-offset, 0 )
//
// offset = balloon_radius * 0.7    (intentional overlap -> reads as cluster)
//
// Apply rotation (cosA, sinA) to each (dx, dy):
//   rotDx = dx*cosA - dy*sinA
//   rotDy = dx*sinA + dy*cosA

// === Spiral color rotation ===
// For balloon b in cluster c with N colors, spiral_step s:
//   color_index = (c*s + b) mod N
//
// With N=4, s=1: cluster 0 -> [0,1,2,3]
//                cluster 1 -> [1,2,3,0]
//                cluster 2 -> [2,3,0,1]
//                cluster 3 -> [3,0,1,2]   (then repeats)

// === Min repeat (informational) ===
//   min_repeat = N / gcd(N, 4)
//   N=2: 1     N=3: 3     N=4: 1     N=5: 5     N=6: 3

    What this demonstrates (and what it does NOT)

    Demonstrated: 4-balloon cluster atomic unit; spiral color rotation; math-driven cluster placement along a curve; vanilla JS + inline SVG (no React, no build step).

    NOT demonstrated yet: garland organic-flow randomness rules; no-touching-twins constraint; 60/30/10 size mix; backdrop sqft -> cluster grid; column gravity rules; drop physics; bouquet anchor + inflation pattern. Each needs its own physics-render-reference page before implementation.
