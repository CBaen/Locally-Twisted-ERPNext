Physics Render Reference - Balloon Arch (Three.js port)

Direct port of GL's BalloonScene from locally-twisted-app/src/components/balloon-preview-3d.tsx into vanilla Three.js (no React, no React Three Fiber). Same library GL ships with: Three.js 0.182. Loaded from CDN via importmap. CDN script tag works in a Frappe portal page.

Math is verbatim from generateArchBalloons(). Scene setup (lights, fog, camera, ground, OrbitControls, materials) verbatim from BalloonScene + BalloonInstances in the same file.

    Physics math (binding reference for Frappe build)

    // === generateArchBalloons - direct port from balloon-preview-3d.tsx ===
// 11" balloon = 0.458 ft radius = 0.917 ft diameter
// 40 balloons per 5 feet of arch (industry standard)
// archWidth  = archLengthFt * 0.5
// archHeight = archLengthFt * 0.4
// offsetFromCenter = balloonRadius * 0.85   (slight compression for density)
// spiralAngle = PI / 4                       (45 degrees per cluster)
//
// For balloon i:
//   clusterIndex     = floor(i / 4)
//   balloonInCluster = i % 4
//   t                = clusterIndex / (totalClusters - 1)
//   angle            = t * PI                 (0 left foot -> PI right foot)
//
//   curveX           = cos(angle) * (archWidth/2)
//   curveY           = sin(angle) * archHeight
//
//   normalX          = cos(angle)             (radial outward)
//   normalY          = sin(angle)
//
//   clusterRotation  = clusterIndex * spiralAngle
//   angleInCluster   = balloonInCluster * (PI/2) + clusterRotation
//
//   offsetRadial     = cos(angleInCluster) * offsetFromCenter
//   offsetZ          = sin(angleInCluster) * offsetFromCenter
//   offsetX          = normalX * offsetRadial
//   offsetY          = normalY * offsetRadial
//
//   x = curveX + offsetX * radiusJitter + posJitterX
//   y = curveY + offsetY * radiusJitter + posJitterY
//   z = curveZ + offsetZ * radiusJitter + posJitterZ
//   scale = balloonDiameter * sizeVariation   (0.95 to 1.0)
//
// Color logic by Style:
//   SWIRL:   colorIndex = balloonInCluster % colors.length      (max 4 colors)
//   LAYERED: colorIndex = floor(clusterIndex / 2) % colors.length (max 8)
