Contestant 2 — The Coloring Book That Assembles Itself

Round 1 mockup gallery. Mobile-first (375px). Vanilla JS + jQuery. No build step, no framework. Frappe-native.

Concept

The Coloring Book That Assembles Itself

A customer arrives at an illustrated canvas with one blank shape ready to be colored. They tap a region, the bottom picker slides up, they choose. The shape comes alive. A ghost placeholder invites the next piece. The composition grows by invitation — no wizard, no steps, no checkout.

  • Interaction: Tap-to-fill on named SVG regions (jQuery event delegation)
  • Color picker: Bottom sheet with recent-used row + hue-family tabs + hex display
  • Composition: Fixed left-to-right arrangement; ghost placeholders as discovery upsell
  • Inquiry output: Design card with palette strip — "Send this to Jeff" CTA
  • Stack: Frappe www/design-studio.html + page <style>/<script> blocks. Zero forbidden primitives.

Key Design Decisions

Tap-to-fill vs. brush: Coloring book apps show tap-to-fill is more approachable for non-designers (Adobe Aqua review). SVG named region fills require zero coloring skill.

Bottom sheet picker: Recolor's "swipe from bottom" pattern (diycandy.com) confirms this is the mobile-native position — within thumb reach, doesn't obscure the composition above.

Hue-family chunking: UXPin color system guide shows 10-11 swatches per group is optimal for visual scanning. 50+ colors chunked into 6 families = ~8 per tab.

Ghost placeholder upsell: Inspired by Fanfaire's SWAP mechanic — place the suggested piece in the right position spatially so the customer doesn't have to imagine placement.

No free-drag composition: Intentional — drag-and-drop at 375px is error-prone and introduces spatial reasoning overhead. Fixed left-to-right arrangement conveys "event setup" without cognitive load.

Design card = capture moment: PilaMania pattern — "you decide when it's ready, submit with no obligation." The design card is the moment it crystallizes, before any database state is involved.
