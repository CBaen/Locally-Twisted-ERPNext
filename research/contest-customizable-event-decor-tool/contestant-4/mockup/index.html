Concept: The Coloring Book

Every screen is grounded in the coloring-book metaphor: outlined shapes waiting for color, a curated palette of named balloon colors, regions that highlight before filling. The composition is a scrapbook spread — horizontal, browseable, each piece independent. Discovery is organic: coloring one thing makes you want to color the next. The output is always an inquiry, never a cart.

Stack: Vanilla JS + jQuery · Inline SVG · Plain CSS · No NPM · No build step · Frappe-native
