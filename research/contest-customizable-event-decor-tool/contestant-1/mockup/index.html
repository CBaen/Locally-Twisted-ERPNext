The Color Stage — Design Principles

  • Coloring book feel, not form feel. Tap a region, pick a color, watch it fill. No dropdowns, no selects.
  • Stage accumulates, never locks. Any piece is re-editable at any time. No linear wizard steps.
  • Palette is catalog. 50+ LT balloon colors, grouped by family. No freeform color wheel — these are real balloons Jeff can source.
  • Discovery through color inheritance. Suggested pieces are shown in the customer's own palette — the next arch already looks like it belongs.
  • Ends with inquiry, not cart. "Send to Jeff" is the only CTA. Design is pre-filled into the inquiry form. No price shown during design.
  • Frappe-native. Inline SVG in Web Page HTML content. Script section for JS. web_include_css for shared styles. Zero NPM, zero build step.
  • Mobile-first 375px. Horizontal swatch scroll (44px hit area), bottom sheet palette, stage strip horizontal scroll.
  • V1 floor: 1 shape, 2 fill zones, 12 swatches, mailto inquiry. Everything else is Stage 2.
